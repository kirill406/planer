## [0.1.0-alpha] — 2026-10-28

Первый MVP для презентации и проверки спроса.

### Добавлено

- Движок плана `engine.js`: расписание от начала или «закончить к», классификация старта (раньше / вовремя ±1 мин / позже), пропорциональное сжатие несфиксированных пунктов с лимитом, прогноз финиша и отставания, итоги, подсказки по медиане последних запусков, разбиение пункта; 33 теста `node --test`
- Приложение `/app` (PWA): список планов и шаблоны (в т. ч. два демо-сценария), редактор с фиксированными пунктами и лимитом сжатия, экран выполнения с кольцом-таймером, сообщениями «идём с запасом» / «опаздываем», уведомлением, звуком и отсчётом опоздания; строка состояния и заголовок вкладки; итоги с кнопками «сохранить / увеличить / разбить»; ускорение времени ×10/×60; управление кликером; офлайн-кэш; состояние переживает перезагрузку
- Лендинг `/`: живое демо пересчёта на настоящем движке, варианты для сегментов `?s=events` и `?s=adhd`, тарифы «фейковая дверь», форма раннего доступа с honeypot
- Бэкенд: FastAPI, CLI `planer` (миграции + uvicorn), SQLite по умолчанию и Postgres по `PLANER_DATABASE_URL`; заявки `POST /api/leads` (дедупликация по email), события `POST /api/events` (белый список), `/admin` с воронкой и CSV; Alembic-миграция `0001`; Docker
- Документация: `AGENTS.md`, `specs/` (спека, дорожная карта с критериями проверки спроса, спеки 001–003), `docs/architecture.md`; git-хуки `pre-commit` и `commit-msg`
