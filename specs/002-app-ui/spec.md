# Спецификация: 002-app-ui — приложение `/app`

**Статус:** Done (0.1.0-alpha)
**FR:** FR-1…FR-18 · **NFR:** NFR-1, NFR-3

## 1. Экраны (hash-роутинг)
| Маршрут | Экран |
|---|---|
| `#/` | Список планов, шаблоны, настройки (демо-скорость, уведомления) |
| `#/plan/<id>` | Редактор: название, начало/«закончить к», лимит сжатия, пункты (минуты, «фикс.», порядок), расписание, «Начать» |
| `#/run` | Текущий пункт: кольцо-таймер, «Закончить», «Пропустить», «Стоп»; дальше — выделенное время (сжатое видно) |
| `#/summary/<runId>` | Итоги и подсказки: сохранить / увеличить / разбить / оставить |

Строка состояния закреплена сверху на всех экранах, пока идёт запуск,
и дублируется в `document.title`.

## 2. Решения
- Состояние: `store.js` — `localStorage` (`planer.v1.*`), запуск сохраняется
  при каждом изменении → переживает перезагрузку.
- Уведомления: `ServiceWorkerRegistration.showNotification` (работает и на
  Android), иначе `new Notification`; всегда — тост в странице, звук (WebAudio),
  вибрация.
- Демо-скорость задаётся до старта и хранится в запуске (`clock`).
- Тексты — только из `strings.js`.
- Тёмная тема по `prefers-color-scheme`.

## 3. Критерии готовности
- Сценарий из шаблона «Демо» проходит целиком при ×60 за ~2 минуты:
  старт → превышение → уведомление → поздний старт следующего → сжатие →
  итоги → подсказка применяется к плану.
- Перезагрузка в середине запуска не теряет состояние.
- Вёрстка 375 px без горизонтального скролла.
