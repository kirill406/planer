# Спецификация: 003-landing — лендинг и сбор спроса

**Статус:** Active
**FR:** FR-19, FR-20 · **NFR:** NFR-5

## 1. Назначение
Проверить спрос: сколько посетителей готовы оставить контакт и нажать «Купить»
на тарифе, из каких сегментов.

## 2. Лендинг `/`
Блоки: hero (обещание + «Попробовать бесплатно» → `/app` + «Хочу ранний доступ»),
проблема, «Как работает» (3 шага), живая мини-демонстрация пересчёта,
для кого (личное/СДВГ, мероприятия/встречи), тарифы, FAQ, форма заявки.

Тарифы — «фейковая дверь»: Free / Pro 299 ₽/мес / Команда 990 ₽/мес.
Кнопка тарифа → событие `pricing_click{tier}` → форма с выбранным тарифом и
пометкой «Оплата откроется скоро, ранним — скидка 50%».

## 3. API
| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| POST | `/api/leads` | `{email, segment, tier, comment, session_id, website}` | `{ok, created}` |
| POST | `/api/events` | `{name, session_id, props}` | `{ok}` |
| GET | `/admin` | Basic auth `admin:$PLANER_ADMIN_PASSWORD` | HTML воронки |
| GET | `/admin/leads.csv` | Basic auth | CSV (UTF-8 с BOM) |

- `website` — honeypot: заполнен → `ok`, но не сохраняется.
- Повторный email обновляет заявку (сегмент, тариф), не дублирует.
- Без пароля `/admin` отвечает 404.
- `session_id` — случайный ID в `localStorage`, без cookies и сторонних счётчиков.

## 4. Критерии готовности
- Тесты API: создание, дубль, валидация, honeypot, события, доступ к админке, CSV.
- Лендинг 375 px без горизонтального скролла, тёмная тема.
