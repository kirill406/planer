# Specs

`specs/spec.md` — общая спецификация: цели, FR/NFR, границы.
`specs/plan.md` — дорожная карта по фазам и критерии валидации.
Фичи: `specs/NNN-slug/` → `spec.md` (что/зачем) + `plan.md` (как, для крупных фич) + опционально `tasks.md`.

Порядок работы: взять первую Active → реализовать → тесты → перенести в Done
одной фразой → `CHANGELOG.md [Unreleased]`.
